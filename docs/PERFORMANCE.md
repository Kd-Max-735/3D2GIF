# 性能报告

流式策略在任一时刻仅保留当前 RGBA 帧、翻转后的帧、Worker 量化工作区和逐步增长的 GIF 字节流，不缓存全部 60 张 RGBA。每帧 Worker 回执后主线程才继续，并通过零延时任务让出事件循环。

本机 Chromium 自动化结果：默认 512×512、60 帧、256 色、无抖动的标准 GLB 导出约 2.3 秒，验收上限 120 秒。20 次连续重新加载在显式 GC 后的 JS Heap 增量门限为 64 MiB，测试通过。单帧预计工作内存超过 256 MiB、边长超过 2048 或帧数超过 1800 时会提前拒绝。

复现性能路径：

```bash
npm run test:performance
```

Floyd–Steinberg 抖动逐像素扩散误差，会明显增加 Worker CPU 时间；大尺寸、复杂阴影和高帧数也会线性增加耗时。GPU 驱动、浏览器后台节流和模型复杂度会影响绝对数据。
